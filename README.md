# questions

A set of short mathematical essays on the geometry of probability and language models —
written as a sequence of questions worked through from first principles.

| Document | Topic |
|----------|-------|
| `llm-geometry` | Next-token prediction as geometry: embeddings, logits, softmax |
| `curvature` | Curvature of the "meaning manifold" and the KL step |
| `information-geometry` | Fisher metric, divergences, and the geometry of statistical models |
| `radon-nykodim` | The Radon–Nikodym derivative and its role in information measures |
| `monte-carlo` | Monte Carlo estimation |
| `surprise` | Surprise / self-information |
| `four-shadows` | — |

Each `.tex` compiles to its `.pdf` with `tectonic <file>.tex`.
